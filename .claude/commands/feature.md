# Feature

Read AGENTS.md and relevant rules. Clarify the feature with the user and write a focused design for $ARGUMENTS (behavior, boundaries, failure modes and acceptance tests) in a file under your scratchpad, and give the user its path. Obtain one adversarial design review from the architect agent, then one from `ce:devils-advocate`, passing each the design; apply their findings without sending the design back for a second pass. Implement in an isolated worktree with independent subtasks delegated only when useful; each delegated brief carries the constraints in rules/agent-ops.md and asks for its deliverable in a file. Run the project check command and exercise the feature through the actual interface. Use project-documented development servers and test harnesses; stop only processes you started. Request the `code-reviewer` agent once, address its findings, and create a PR using the repository template. Merge only when authorized and checks pass. Preserve deliverables and clean up the task worktree after handoff.
