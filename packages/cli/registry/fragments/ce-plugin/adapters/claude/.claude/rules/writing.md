# Writing

Load the `ce:writer` skill when writing documentation, READMEs, commit messages, or PR descriptions.

- Plain, specific, and short. Say what something does and how to use it; skip claims about how significant it is.
- Commands in docs must be ones that exist in the project and work as written.
