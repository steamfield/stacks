# Architecture

A server-rendered web app on the standard library's `net/http`. The server
renders every page as HTML; htmx, loaded from a vendored file, swaps parts of
the page when a form posts. There is no JavaScript build.

```text
cmd/server/          main: config, logger, listener, graceful shutdown, -healthcheck
internal/config/     environment settings with validated defaults
internal/errors/     domain error codes (Invalid carries field messages)
internal/log/        the JSON slog logger every package receives
internal/notes/      the proving domain: validation and a context-aware Store
internal/views/      templ components (*.templ), their generated *_templ.go, view types
internal/web/        routes, middleware, form handling, the error table and render helpers
static/              embedded assets: app.css and vendor/htmx.min.js
tests/integration/   the built binary over real HTTP
```

## Request path

`identify` (request id) wraps `accessLog`, which wraps `recoverPanic`,
`secureHeaders`, then `crossOrigin` (the standard library's
`http.CrossOriginProtection`) and finally the `ServeMux`. A mux miss keeps the
mux's 404 or 405 decision and its `Allow` header but renders the error page.

Handlers load data through a domain `Store`, convert it to view types and call
`render`, which renders the component into a buffer before writing the status,
so a failing component becomes the error page instead of half a response.
Errors returned from an `endpoint` go to `renderError`, which picks the status
and the page text from `errorTable` and logs the cause of server faults.

## Dependency direction

`web` imports `views`, `notes`, `errors` and `static`. `views` imports nothing
from the project: components take the plain types in `views/models.go`. Domain
packages never import `web` or `views`.

## Generated code

`internal/views/*_templ.go` is generated by `make generate` from the `.templ`
files and committed. `make generate-check` fails when it is stale or edited.
golangci-lint and `make fmt-check` skip generated files.
